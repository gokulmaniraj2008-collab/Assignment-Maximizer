Non-Linear Programming Solver

Learn the exact classroom problem step-by-step — with boundary cases and the final maximum.

Given Problem

Max Z = 10x₁ + 10x₂ − x₁² − x₂²
x₁ + x₂ ≤ 8
−x₁ + x₂ ≤ 5
x₁, x₂ ≥ 0

1. Check the unconstrained optimum

1
∂Z/∂x₁ = 10 − 2x₁ = 0 → x₁ = 5
2
∂Z/∂x₂ = 10 − 2x₂ = 0 → x₂ = 5
(5,5) is not feasible because 5 + 5 = 10 > 8. So the constrained maximum must lie on a boundary.

2. Check the important boundaries

Boundary x₁ = 0

Z = 10x₂ − x₂², with x₂ ≤ 5

x₂ = 5 → Z = 25

Boundary x₂ = 0

Z = 10x₁ − x₁², with x₁ ≤ 8

x₁ = 5 → Z = 25

Boundary −x₁ + x₂ = 5

x₂ = x₁ + 5. Feasible range gives the best endpoint x₁ = 1, x₂ = 6.

Z = 33

Boundary x₁ + x₂ = 8

x₂ = 8 − x₁

x₁ = 4, x₂ = 4 → Z = 48

3. Work the winning boundary

x₂ = 8 − x₁

Substitute into the objective:

Z = 16 + 16x₁ − 2x₁²

Differentiate:

dZ/dx₁ = 16 − 4x₁ = 0 → x₁ = 4

Therefore:

x₂ = 8 − 4 = 4

Final Answer

x₁ = 4    x₂ = 4

Maximum objective value:

Zmax = 48

All constraints are satisfied, and 48 is greater than the best values found on the other boundaries.

Seminar Explanation

“First, I find the unconstrained stationary point, which is (5,5). Since it violates x₁+x₂≤8, I check the feasible boundaries. The boundary x₁+x₂=8 gives x₁=4 and x₂=4. Substituting these values gives Z=48, which is the highest feasible value. Therefore, the optimal solution is x₁=4, x₂=4 and Zmax=48.”
